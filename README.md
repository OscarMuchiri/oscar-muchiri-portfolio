# Oscar Muchiri — Portfolio

Personal portfolio built with **Next.js, TypeScript and Tailwind CSS**.

The site presents selected work across:

- Machine Learning
- Computer Vision
- Software Engineering
- Business Intelligence
- Geospatial Systems
- IoT / Edge AI

## Featured projects

- [Gold Trend Forecasting](https://github.com/OscarMuchiri/Gold-Trend-Forecasting-ML)
- [Road Damage Detection with YOLOv8](https://github.com/OscarMuchiri/road-damage-detection-yolov8)
- [Car Sales BI Dashboard](https://github.com/OscarMuchiri/Car-sales-Bi-Dashboard)
- [Home Security System](https://github.com/OscarMuchiri/Home-Security-System)
- [Heart Disease Prediction](https://github.com/OscarMuchiri/Heart-Disease-Prediction)

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Deployment

The project is ready for deployment on Vercel. Connect this GitHub repository in Vercel and deploy using the default Next.js settings.

## Design direction

Dark, minimal and technical:

- near-black background
- slate surfaces
- cyan accent
- responsive layout
- subtle grid / glow effects
- accessibility-aware reduced-motion behaviour
